📊 Electronic Sales Dashboard (2020–2023) | Data Analytics Project
📌 Project Overview

This project showcases an interactive Electronic Sales Dashboard built using Power BI and Power Query, designed to analyze electronic product sales data from 2020 to 2023.

The dataset contains 14,400+ records, enabling in-depth analysis of sales performance, product demand, brand contribution, and regional trends. The dashboard transforms raw data into actionable insights to support data-driven decision-making.
---

🔍 Key Highlights (KPIs & Insights)
📊 Total Sales: 5M+ revenue generated across all years
💰 Total Cost: 4M+ tracked to evaluate profitability
📈 Total Profit: 1M+ overall margin achieved
📦 Total Quantity Sold: 698 units across categories
🧾 Total Transactions: 280+ sales records analyzed

---
📦 Category-Wise Performance
Top-Selling Products: Monitor, Mouse, CPU, Keyboard
Mid-Range Demand: SSD, Cabinet, HDD, Graphic Card
Low Demand: RAM, Motherboard, Printer, NIC

---
🏢 Brand Contribution Analysis
Leading Brands: Dell, Samsung, Intel
Moderate Performers: Nvidia, Western Digital
Niche Players: Acer, Hynix, Seagate, Gigabyte
